# Support

Before reporting a problem:

1. Confirm the issue occurs on the documented Unity version.
2. Run **Tools > Scene Zone Tools > Validate Project**.
3. Reproduce it in a new empty scene if possible.
4. Include the tool version, Unity version, operating system, reproduction steps, Console output, and an affected layer asset when it is safe to share.

Feature requests should describe the authoring problem rather than only a proposed interface. Runtime game-specific bindings are intentionally left to consuming projects.
